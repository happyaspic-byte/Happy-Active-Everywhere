처음 연결하기

01

장치 등록

장치 추가에서 초대 파일을 내려받아 해당 장치에 전달하세요. 각 장치에 everywhere를 설치하고 초대 파일을 한 번 가져옵니다.

everywhere enroll --state STATE --invitation INVITE.json --name "내 장치"
02

승인 · 에이전트 실행

등록한 장치의 지문을 확인해 웹에서 승인하세요. 각 장치에서 에이전트를 실행하면 상태가 표시됩니다.

everywhere manage --state STATE

자동 실행은 설치 문서의 service install을 이용하세요.

03

폴더 연결

폴더 연결에서 두 장치, 각 장치의 경로와 연결 주소를 선택하세요. 세 번째 장치는 같은 폴더 ID로 기존 장치에 추가 연결합니다.

오프라인 장치의 명령은 대기하며, 적용 결과는 명령 기록에 남습니다.

04

변경 검토

장치 상세에서 작업을 일시정지하거나 재개할 수 있습니다. 삭제 승인, 충돌 해결, 이전 버전 복원은 해당 폴더에서 검토하세요.

실행 중 표시는 프로세스 상태입니다. 실제 교환 완료 여부는 마지막 동기화 완료 시각으로 구분합니다.

새 장치 초대

초대 파일은 한 장치에만 사용할 수 있고 24시간 뒤 만료됩니다.

등록할 장치에서 내려받은 파일을 가져오세요.

everywhere enroll --state STATE --invitation everywhere-invitation.json --name "내 장치"

이후 장치 목록에서 지문을 확인하고 승인하세요.

초대 파일을 공개 저장소나 게시판에 올리지 마세요.
