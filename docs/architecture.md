# 설계·지원 범위 — 2026-09-21

## 목표와 단계
정확성·복구 가능성 → 성능·자원 효율 → 편의성 → 고급 기능 순서.
현재 첫 단위는 별도 합성 폴더에서 쓰는 단일 파일 전송 CLI 알파다.
제품명 `everywhere`는 로컬 명령 이름이다. Resilio 프로토콜 호환성을 주장하지 않는다.

## 구성
- Rust + Tokio 에이전트: TCP + rustls TLS 1.3, 장치별 인증서·개인키, 명시적 신뢰 등록.
- 알파: 승인된 인증서만 신뢰하는 mTLS, 피어 인증서 fingerprint 재확인, 파일 단위 수신 권한.
- 이후: SQLite 인덱스·버전 벡터·삭제 기록·작업 저널, 폴더별 권한 및 정책.
- 중앙 서버는 정책·장치·관측 제어 담당. 파일 데이터는 피어 간 직접 전송.
- 승인 정책은 에이전트 로컬에 영속화. 서버 중단 중 기존 동기화 지속.
- 권한 회수는 로컬 반영 시 즉시 적용. 단절된 장치에는 재연결 시 전달. 오프라인 즉시 회수는 보장할 수 없다.
- React + TypeScript 관리 화면은 인증 API를 통해 실제 에이전트 작업을 제어.

## 첫 전송 프로토콜
장치별 자체서명 인증서를 명시적으로 교환하여 각 상대 인증서만 신뢰한다.
표준 rustls 검증을 사용하며 인증 검증 생략 또는 자체 암호 구현은 허용하지 않는다.
인증서 SAN은 고정 프로토콜 이름이며 장치 정체성은 승인된 DER 인증서에 결합한다.
1 MiB 고정 블록, BLAKE3 전체 파일·블록 해시, 최대 1 TiB / 1,048,576블록.
수신자가 요청한 인덱스만 전송. 네트워크 프레임 크기·대기 시간·동시 연결 제한.
파일 이름·경로는 수신자가 지정하며 원격 경로 입력을 파일 시스템에 적용하지 않는다.
송신자는 manifest 해시 후 각 요청 블록을 재검증. 변경 감지 시 반영 전 중단.
수신 재시작 시 임시 파일의 블록을 다시 해시한다. 메타데이터만으로 완료를 신뢰하지 않는다.
현재 대상 파일의 같은 위치에 있는 일치 블록을 재사용한다.
전체 해시 확인·파일 fsync 후 기존 버전 보존 및 원자적 교체, 디렉터리 fsync.
동일 대상에 대한 수신 작업은 파일 잠금으로 직렬화. 심볼릭 링크를 거부한다.
로컬 사용자가 수신 도중 대상 파일을 바꾸면 충돌 오류로 보존한다.

## 데이터/복구 모델 (후속 구현 설계)
각 폴더·장치별 증가 카운터와 버전 벡터로 인과관계 비교. 벽시계는 표시 전용.
서로 지배하지 않는 버전과 삭제/수정 경합은 충돌로 양쪽 내용을 보존.
삭제는 tombstone으로 영속화. 승인 장치가 인지하기 전 자동 정리하지 않는다.
수신 변경은 staging → verified → version-preserved → installed 단계로 기록.
파일 반영과 SQLite 트랜잭션 사이 중단은 시작 시 해시·저널 대조로 복구.
DB 손상 시 격리 후 파일 재인덱스. 인과관계 복구 전 삭제 전파 중지.
마운트 루트의 식별 marker와 파일시스템 정체성 확인 실패 시 폴더 정지.
대량 누락은 삭제 승인 보호장치 적용. 공간 부족·권한 오류에서는 기존 파일 유지.
실행 중 DB·VM 디스크 동기화는 일관성 보장 백업이 아니다.

## 기준선과 검증 계획
독립 SHA-256 + 상대 경로 목록으로 누락·불일치 검사. 합성 데이터만 사용.
실제 CLI 두 프로세스 정상 전송 및 강제 종료·재개 각각 2회 이상.
미승인 인증서, 잘못된 블록, 경로 탈출, 원본/대상 변경, 공간·권한 오류 테스트.
10 GiB·100 GiB, 100,000·1,000,000 작은 파일, 2·3~10장치, LAN/WAN 분리 측정.
네트워크·읽기·쓰기 상한을 각각 측정 후 최저값의 80% 목표와 비교.
캐시 warm/cold 구분. 처리량·CPU·최대 RSS·1 MiB 반영 지연 p95 기록.
RSS 목표 유휴 256 MiB / 전송 512 MiB, 변경 p95 목표 2초.
현재 여유 약 96 GiB: 100 GiB 및 원본+대상+이전 버전 공간 확보 불가.
로컬 loopback 결과는 실제 LAN/WAN 또는 실제 두 장비 결과로 취급하지 않는다.
72시간 베타·7일 안정 후보 시험과 동조건 Resilio Sync 비교는 별도 실측 필수.
QUIC·가변 청킹·압축·다중 피어는 기본 경로 측정 후 비교 실험.
온디맨드·캐싱·고정·Finder/Explorer·분산 잠금은 안정 기본 기능 이후.
